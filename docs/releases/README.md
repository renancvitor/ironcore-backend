# Releases

Este diretório preserva a documentação histórica dos releases do IronCore Backend.

Cada release possui seu próprio `README.md` para facilitar navegação direta pelo GitHub e evitar sobrescrita de documentação histórica.

## Índice

| Release | Documento | Status |
|---|---|---|
| `v0.1.0` | [Fundação técnica do backend](./v0.1.0/README.md) | Histórico |
| `v0.2.0` | [Users, auth e security single-user](./v0.2.0/README.md) | Atual |

## Regra de Manutenção

- Não sobrescrever documentação de release anterior.
- Criar uma nova pasta por release somente depois de haver fechamento público ou técnico relevante.
- Manter o README principal do projeto como visão geral; detalhes técnicos devem ficar nos documentos de release ou nos módulos dentro de `docs/`.
